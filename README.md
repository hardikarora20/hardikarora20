## 🍑 Featured Project — Peach

<table>
<tr>
<td width="60%">

**Peach** is a social / dating-style web app I'm building end-to-end — onboarding, profiles, matches and real chats, wrapped in a modern, material-inspired, animated UI with dark mode. 🌙

**What's inside:**

- 🔐 **JWT auth** + **OTP email verification** on sign-up
- 💌 Branded, minimal **HTML OTP emails** sent via **Brevo**
- 👤 Onboarding flow & rich profiles (Gen-Z profiles have cats, food and sunsets too 🐱🍜🌅)
- 💞 Matches & 💬 chats
- 🎞️ Smooth page transitions and sliding / fading component animations
- 🌗 Dark theme, full-screen responsive layouts

**How it's shipped (100% free tier 💸):**

- ⚙️ Backend → **Spring Boot** in **Docker** on **Render**
- 🎨 Frontend → **React** on **Vercel**
- 🐘 Database → **PostgreSQL** on **Neon** (H2 for local dev)
